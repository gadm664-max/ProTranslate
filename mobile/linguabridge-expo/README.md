# LinguaBridge Expo Mobile

هذا المجلد يحتوي تطبيق LinguaBridge الأصلي لـ Android وiOS، ويظل منعزلًا عن مشروع ProTranslate القائم. لبناء ملف معاينة Android، افتح تبويب **Actions** في GitHub وشغّل **Build LinguaBridge Android Preview APK**. بعد نجاح التشغيل ستجد ملف التثبيت تحت قسم **Artifacts** باسم `LinguaBridge-Android-preview-APK`.

لا يعتمد هذا المسار على Expo Go أو نفق التطوير؛ ينتج APK Debug قابلًا للتثبيت للاختبار الداخلي.
